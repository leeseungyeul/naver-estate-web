손님이 단지 4개를 들고 와서 "어디가 좋아요?" 물어보면 보통 답변까지 30분 이상 걸립니다.
호가·면적·주차·관리비를 단지마다 따로 검색해서 비교표를 만들어야 하기 때문이죠.
이 사이트의 **[/compare](/compare) 단지 비교 화면은 4개 단지를 한 화면에 24행으로
줄세워 5분 안에 자료를 끝낼 수 있도록** 설계했습니다.

검색 결과에서 + 버튼 4번, 비교하기 클릭 1번. 끝.

비교표 행은 **기본 23행 + 동적 평당가 1행 = 총 24행**입니다. 각 행은 손님이 매수 결정에서
실제로 묻는 항목으로만 추렸어요.

**기본 정보 8행** — 주소·도로명·매물유형·세대수·동수·최저층·최고층·준공일

**평면·주차·시설 9행** — 최소면적·최대면적·총주차·세대당 주차·난방·난방연료·시공사·용적률·건폐율

**시세·매물 6행** — 평당가(동적 삽입)·매물수·주변 중위가·전세가율·수영장·관리사무소

평당가는 매수 비교의 가장 강력한 지표라서 **인덱스 17 위치(건폐율 다음)에 동적으로 끼워 넣었습니다**.
실거래가 데이터에 면적별 거래가 있으면 가중평균(가격÷평 × 거래수 / 총거래수)으로 자동 계산됩니다.

## ★ 우위 판정 — 어느 단지가 이기나

24행 중 **숫자 비교가 가능한 14행에만 ★ 우위 표시**가 자동으로 붙습니다. 손님이 표만 봐도
"이 단지가 이 항목에서 가장 좋구나" 한눈에 보이도록요.

**클수록 좋은 항목 (11)** — 세대수, 동수, 최고층, 최저층, 준공일(최신), 최대면적, 총주차,
세대당 주차, 매물수, 주변 중위가, 전세가율

**작을수록 좋은 항목 (3)** — 용적률, 건폐율, **평당가**

평당가가 lower better 인 이유는 같은 입지·세대 조건에서 **㎡당 단가가 낮을수록 매수자 입장에서
유리**하기 때문입니다. 손님께 "여기가 평당가 가장 낮으면서 세대당 주차도 가장 많아요" 같이
한 줄로 자료를 만들 수 있죠.

## 5분 워크플로 — 검색에서 비교까지

손님 앞에서 1분 안에 자료가 떨어지도록 설계했어요.

1. **단지 검색** — 상단 검색창에 동·아파트명 입력 → /search 결과 테이블에서 마음에 드는 단지의 **+** 버튼 클릭. 즐겨찾기 별표(★)와 비교 +가 액션 열에 같이 있어요.
2. **플로팅 바 확인** — 화면 하단에 "비교 목록 (1/4)" 플로팅 바가 자동으로 뜹니다. **최대 4개**까지 추가 가능 (5번째는 경고).
3. **비교하기 클릭** — `/compare?ids=12345,67890,...` URL 로 이동, useQueries 병렬 조회로 한꺼번에 채워집니다.
4. **표 + 차트 확인** — 24행이 펼쳐지고 ★ 표시로 우위 항목이 보입니다. 표 아래 5종 차트가 자동 생성됩니다.

## 차트 5종 — 한눈에 비교

- **레이더 차트 (8축)** — 세대수·세대당 주차·전세가율·매물수·신축도·주변 시세·최고층·**평당가(invert) 가중치 적용**
- **시세 추이 차트** — 매매·전세 6개월/1년/2년/전체 기간 필터, 단지별 색상 구분
- **평균가 막대 차트** — 매매(★빨강)·전세(★파랑)·월세(★초록), 거래유형별 최저 단지에 ★
- **층별 비교 차트** — 저층·중층·고층 3구간별 매매가

표 아래에는 **상세 데이터 테이블 3종**도 추가됩니다 — 면적별 매매·전세 가격, 관리비,
세대구성. 아코디언으로 접혀 있어 클릭해서 펼치면 됩니다.

## 인쇄·엑셀·URL 공유

자료를 손님께 전달하는 방법도 3가지를 갖췄습니다.

**인쇄** — 우측 상단 "인쇄" 버튼 클릭. 아코디언이 자동으로 모두 펼쳐지고
(`expandAll + rAF 2회`) `@media print` CSS 가 좌우 여백·폰트 크기를 인쇄용으로
조정합니다. 종이 한 장(A4)에 표 + 차트가 깔끔하게 떨어집니다.

**엑셀** — "엑셀 다운로드" 버튼은 ExcelJS 로 `단지비교_2026-05-07.xlsx` 파일을 즉시
생성합니다. 셀 값에 `=`·`+`·`@`·`-` 로 시작하는 텍스트가 있으면 **수식 인젝션 방어**로
앞에 작은따옴표(`'`)를 자동 붙입니다 (악의적 셀에서 매크로 실행 차단).

**URL 공유** — `/compare?ids=12345,67890,11111,22222` 형식으로 바로 링크가 됩니다.
손님 카톡에 그대로 붙여넣으면 손님 화면에서도 동일한 비교가 떠요.

## /mibunyang/compare 와는 무엇이 다른가

미분양 단지에도 `/mibunyang/compare` 비교가 있는데, 두 비교는 **완전히 다른 흐름**입니다. 차이 5가지: 행 수(24 vs 17)·가격 방향(혼합 vs 전체 lower)·차트(5종 vs 3종)·가중치(invert 자동 vs 프리셋+슬라이더)·히스토리/북마크(없음 vs 있음).

매수 상담은 단지 비교, 분양 상담은 미분양 비교 — 용도가 분리됩니다.
